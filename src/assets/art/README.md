Drop your own character images here to replace the built-in drawings.

Name each file after the texture it replaces, e.g. `hero.png`, `pup-lead.png`,
`pest.png`, `shooter.png`, `bgLawn.jpg`. See `TEXTURES` in `src/art/index.ts`
for every key. PNG/WebP with a transparent background works best for characters.

These replace the art in both editions (see `src/edition.ts`), and get published with any build.
